# 📝 Simple Text Editor

Simple text editor built with **Java Swing**.

### ✨ Features
- Open, edit, save `.txt` files
- Spell check
- Document metrics
- Line numbers

### 📁 Files
- `TextEditorApp.java` (main)
- `LineNumberGutter.java`
- `SpellCheckerEngine.java`
- `DocumentMetrics.java`

### 🚀 How to Run
```bash
javac *.java
java TextEditorApp
```
