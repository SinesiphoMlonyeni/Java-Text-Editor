# Java Text Editor Application

Simple lightweight text editor built with Java Swing for CPUT SDN(Software Design) project.

## Features
- Create, open, edit and save .txt files
- Cut, Copy, Paste
- Word count
- Clean Swing GUI

## How to Run
javac TextEditorApp.java
java TextEditorApp

## Tech Stack
Java, Swing, OOP, File I/O
